# Two-Player Result Rules

## Round behavior

- Both players can answer simultaneously.
- The player who submits a valid answer first determines the round outcome.
- If the first answer is correct, that player wins the round.
- If the first answer is wrong, the other player may still answer while the round is unresolved.
- Once the round outcome is determined, show the correct answer and an explanation.
- The explanation/result screen is intentionally not rushed.
- Every player who participated in the round must acknowledge the result before the next microgame begins.
- A player acknowledges using the normal confirmation input (for example, X).
- When all required players have acknowledged, continue to the next microgame.
- Solo mode requires only the solo player to acknowledge.

## Examples

P1 correct first:
- P1 = correct
- P2 may be unanswered
- Show result/explanation
- Require participating players to acknowledge
- Continue

P1 wrong first, P2 correct:
- P1 = wrong
- P2 gets the opportunity to answer
- P2 = correct
- Show result/explanation
- Require participating players to acknowledge
- Continue

Both wrong:
- Show correct answer and explanation
- Require both players to acknowledge
- Continue only after both acknowledge
